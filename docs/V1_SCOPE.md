# Nila V1 Scope

## Core identity

Nila is a Malayalam-first desktop companion where the animated character is the primary product experience.

## Must ship

- Malayalam UI
- original character
- character animation
- character states
- character interactions
- floating desktop presence
- built-in reminders
- custom reminders
- recurring reminders
- one-time reminders
- quiet hours
- snooze
- pause
- cooldown
- daily limits
- SQLite
- restart-safe schedules
- import/export
- macOS
- Windows
- system tray/menu bar
- dark/light/system appearance
- reduced motion
- basic accessibility

## Must not ship in V1

- multilingual UI
- localization framework
- privacy center
- analytics
- cloud services
- accounts
- authentication
- AI
- LLM
- weather
- fitness
- social features
- Linux
- multiple characters
- character editor
- cloud sync

## Product test

A screenshot showing only a desktop, Nila's character, and a small Malayalam reminder bubble should communicate the product's identity without explanation.
